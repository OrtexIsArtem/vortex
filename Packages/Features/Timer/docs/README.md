# Timer

One timer at a time, started in one click from a preset on Home or in the Timer tab; the time left shows in the closed notch.

| File | What it covers |
| --- | --- |
| behavior.md | starting, pausing, +5 min, when time is up, the notch, relaunch |
| settings.md | presets, sound, flash color |
| data.md | the settings file and the saved run |
| contracts.md | the module, its Home widget and indicator, the clients it uses |
