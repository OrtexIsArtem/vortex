# Timer

One timer at a time, set on a drum next to the notch on Home or in the Timer tab and started in one click; the time left shows in the closed notch.

| File | What it covers |
| --- | --- |
| behavior.md | setting the time on the drum, starting, pausing, +5 min, when time is up, the notch, relaunch |
| settings.md | sound, flash color, the minutes on the drum |
| data.md | the settings file and the saved run |
| contracts.md | the module, its Home widget and indicator, the clients and views it uses |
