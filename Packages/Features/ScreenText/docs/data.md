# Data

Screen Text keeps nothing: no tables, no migrations, no `screentext.json`, no folder.

| What | Where | How long |
| --- | --- | --- |
| — | — | Nothing is stored. |

- The frozen screen and the framed part live in memory while the capture lasts.
- What is copied goes only to the pasteboard; Clipboard, if it runs, keeps it in its own history by its rules.
- Its catalog page shows no "keeps" line and no Erase Data.
- The shortcut lives in KeyboardShortcuts' defaults and stays when the feature is removed, so adding it again keeps it.
- Nothing read is logged: QA mode logs only the sizes of the pictures read.
