# Utility Template

One sentence: the one clear thing this utility does for the user. This one says hello in the closed notch.

| File | What it covers |
| --- | --- |
| behavior.md | what its action does, and what the user sees |
| settings.md | its shortcut, which the shell records, and its own settings |
| data.md | what is stored, where and for how long |
| contracts.md | its utility action, and what it takes from Core and Platform |
