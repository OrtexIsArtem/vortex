# Tasks

A task taken from the screen in three actions: a shortcut freezes it, a frame picks what matters, Return saves it with the app, window title and page it came from; the list finds it by the text on its pictures.

| File | What it covers |
| --- | --- |
| behavior.md | the capture, the list, the card, search, done and undo, permissions |
| settings.md | the shortcut, the Screen Recording row, how long done tasks stay |
| data.md | the tables, the pictures, the recognized text, numbering, cleanup |
| contracts.md | the module, the clients and views it uses from Platform |
