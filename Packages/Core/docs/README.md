# VortexCore

Shared ground for the shell and all features. Depends on The Composable Architecture and GRDB.

| File | What it covers |
| --- | --- |
| FeatureModule.swift, UtilityAction.swift | the contract every feature implements: id, title, symbol, its kind (`FeatureKind`, from its type: a plain `FeatureModule` is a feature and must make its tab; a `UtilityModule` is a utility, which does one clear thing and has no tab and no `makeTab()`; `hasTab` follows the kind), settings, taking files, starting and stopping, Home widgets, its utility actions (`UtilityAction`: at most two one-click actions with a symbol, label, help, the permission a warning names and the name of the shortcut that runs them, which the shell places in Home's utilities dock, records, listens for and runs after making the window what `WindowNeed` says: closed, open or as it is; `UtilityActionInfo` is the same as plain data, the permission too), its cover over the window (`makeWindowCover()`, WindowCover.swift), the permissions it needs with their reasons (`permissionNeeds`), its own onboarding page (OnboardingStep.swift: `OnboardingStep`, and `onboardingStepsDone`, where a feature inserts its id once its step is done, for Next instead of Skip); the catalog's description, plain data the shell reads without running the feature (one line, details, author, recommended, beta, built in, paused, its kind, what it keeps, its erase note and folder, whether it has a step, its preview: FeaturePreview.swift), and `eraseData()` for what only it knows |
| HomeWidget.swift | a feature's widgets on Home: `HomeWidgetSize` (Small 1×1, Medium 2×1, Wide 4×1, Large 2×2, Full 4×2, in exact points), `HomeGrid` (4×2 cells of 143×182 pt, 12 pt apart), `HomeWidgetPlace` (one to three sizes in the order the widget prefers, or the notch row), `HomeWidget` (at most 2 per feature; `problems` lists what breaks the rules) and `HomeWidgetInfo`, the same without its view; the environment values `homeWidgets` and `homeWidgetSize` (the size a widget's view is laid out at); the shared keys `runningHomeWidgets` (only the shell writes it; nil until its first word at launch), `homeAddRequests` (the shell asks, Home takes each request), `featuresOnHome` (only Home writes it) and `noRoomOnHome` (Home adds a feature whose request found no room and takes it out once a widget of it is on Home or its first widget would fit; the shell empties it as the tab changes) |
| HomeWidgetPreview.swift, WindowRequest.swift, UtilitiesDock.swift, WindowCover.swift | `View.homeWidgetCard(size:)`, the card Home lays a widget on, and `HomeWidgetPreview` for a widget's `#Preview`: Home with every cell outlined and the widget at its real size; `WindowRequest` (a window size and the focus) and the environment values `windowRequest` and `showCatalog`, which the shell gives a feature's tab; `UtilitiesDock` and `UtilitiesDockButton`, the environment value `utilitiesDock` the shell gives Home: the running utility actions in catalog order with their symbol, label, shortcut keys and warning, whether the strip is out, and toggle, close and run, which are the shell's (nil outside it: Home's button is the pencil); `WindowCover` and the shared key `windowCover`: a utility's screen over the whole window while it works, written only by that utility, under which the shell keeps the window open and, with `holdsKeyboard`, Vortex in front holding the keys, and which closes the window as it goes |
| NotchIndicator.swift | indicators for the closed notch, how they fill the ears and which feature owns each ear, colored flashes, alarms that flash until seen, and the shared key `notchIndicators` |
| Permissions.swift | `Permission` (title, what its warning says, whether a grant waits for a relaunch, whether macOS grants it in its own prompt), `PermissionStatus`, `PermissionNeed`; the shared keys `permissionStatuses` and `appBlocked`, written only by the shell, empty and false until its first read (a missing status is unknown: no warning); `PermissionPage`, which opens the shell's page for a permission (`openRefused`: one macOS refused while it reads granted, whose page says to turn the switch off and on again): live, it leaves the request (`PermissionPage.Request`) in a channel inside the app that the shell drains with `requests()` from launch on, as feature stores aren't children of its store, and only the latest request waits for it; unimplemented in tests |
| Database.swift, QALaunch.swift | `DataFolder` (~/Library/Application Support/Vortex; in a debug build started with `--qa <name>`, Vortex QA/<name>, read by `QALaunch` with its options; a bad `--qa…` stops the app), under which everything a feature keeps goes; the one SQLite database `@Dependency(\.database)`, `migrate(_:)`, `eraseFeature(_:)` (a feature's tables `<id>_…` and migrations `<id>.…`, for Erase Data), a migrator's `names()` (for each feature's test that they carry its id), and `@Dependency(\.databaseIsOnDisk)`: false when the file didn't open and features work in memory |
| AppPreferences.swift, DesignSystem/ | theme and language values; monochrome palette, window metrics and levels, `WindowSize` (regular 680×440; large 880×440 and dock 736×440, the utilities dock's strip as wide as the sidebar, which grow right), environment values (`notchCutout`, `isWindowOpen`), switch, capsule buttons, segmented picker, settings row, hairline, short ages `Text(age:now:)` (strings in Resources/), `ColorValue` (a color to store and send); the one other color, `VortexColor.warning` (system yellow), drawn by `WarningMark`: a triangle, or a dot for the sidebar, which given a permission says "Notifications are off" as a tooltip and to VoiceOver; `PermissionMark` (yellow only for `notGranted`, ↻ for `grantedAfterRestart`) and `PermissionRows`, a feature's settings rows with "Turn on" or "Restart Vortex", built of pieces a feature's catalog page shows too (`PermissionNeed.title(_:)`, `caption(_:)`, `PermissionButton`, `permissionHelp(_:_:)`) |

- A feature never asks macOS for a permission: it reads the statuses and calls `permissionPage.open(_:)`; while `appBlocked`, its own shortcut does that instead of its work.
