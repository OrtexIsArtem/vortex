# VortexPlatform

System clients and system-backed views; features reach the system only through them, so tests can substitute them. The notch window and the menu bar icon are not here: they belong to Shell.

| File | What it covers |
| --- | --- |
| Clients/HotkeyClient.swift, KeyboardLockClient.swift | global shortcuts: a module declares its own `Hotkey`, listens with `presses`, shows `HotkeyRecorder`; every key held back for cleaning, by an active event tap on the main run loop (keys, modifiers, brightness, sound and media; never the pointer), turned back on when macOS turns it off, needing Accessibility, asked for only on the user's click |
| Clients/PasteboardClient.swift | copies made in any app (checked twice a second), writing to the pasteboard, `AppInfo` |
| Clients/FileClient.swift | file info, reading, writing, copying, deleting, Show in Finder, folder picker, watching a folder |
| Clients/AppsClient.swift, FrontWindowClient.swift, QuickLookClient.swift | running apps, `AppIcon`, opening an app or a page in it; the app in front with its window title and browser page; the Quick Look panel, which Vortex windows hand over through `QuickLook` |
| Clients/LaunchAtLoginClient.swift, SystemClient.swift, SoundClient.swift, NotificationClient.swift | login item; theme, interface language, relaunch (the app opens again once this process is gone; if it is still there after about 10 s, as when the quit was cancelled, nothing opens), quit; system sounds by name; notifications with buttons, shown even while Vortex is active, each press telling which notification it was on, taken back by id prefix (needs the app bundle, so not under `swift test`) |
| Clients/ScreenCaptureClient.swift, TextRecognitionClient.swift, Views/ScreenOverlay.swift | Screen Recording access and a display as it looks, without Vortex's windows (`Screenshot`, `ScreenImage`: crop, PNG, HEIC, read back decoded); text on images by Apple Vision, offline; a window over a whole display, above everything, that gives way when another app comes to the front: with Vortex brought to the front (`show`) or the app in front and the keyboard left as they are (`showKeepingFront`: it never takes the keyboard, takes the keys pressed in Vortex meanwhile and keeps the shell's window open) |
| Views/DragSource.swift, DropTarget.swift, ScrollDragArea.swift, EditingShortcuts.swift, FileThumbnail.swift, ColorWell.swift | drags out (`DragSourceArea`: hover, clicks, several items; a press with nothing to drag stays a click) and in (`dropTarget`); scrolls and presses on a control such as the timer's drum (`ScrollDragArea`); the standard editing shortcuts for panels without a main menu, also under Cyrillic layouts (`EditingShortcuts`); Quick Look thumbnails made in the background, `FileIcon`; a color picker whose panel floats above Vortex |
| Clients/KeychainClient.swift, CommandClient.swift | secrets in the login keychain by service and account; a command in the user's shell with what their terminal's shell exports (asked from a login, interactive shell without a terminal, so `.zshrc` counts; again after a startup file changes, also through a link or under ZDOTDIR, after 10 minutes or after a command isn't found; the login profile only if the shell doesn't answer in 10 s), no input, none of Vortex's environment and a time limit, stopped with everything it started, also when Vortex exits |
| OutsideActivity.swift | whether a drag out, Quick Look, the folder picker or a picture over the whole display is in use, so the shell keeps the window open |
